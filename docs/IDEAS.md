# Feature Ideas

These are ideas, not promises. Promote them into ROADMAP.md only after the core lock/mass-salvage/loadout system is stable.

## Salvage QoL

- Select all eligible items in the current filter
- Select by rarity
- Select below power threshold
- Select duplicates while keeping the strongest copy
- Protect all enchanted items
- Protect all gilded items
- Protect all uniques
- Saved salvage presets
- Optional reward total preview
- Keyboard/controller shortcuts

## Gear organization

- Favorites separate from hard locks
- User tags such as Bossing, Speed, Souls, Emeralds
- Multiple named loadout pages
- Loadout icons/colors
- Notes on items/loadouts
- Compare a loadout against equipped gear
- Quickly cycle loadouts while in camp
- Detect broken loadouts when an assigned item disappears

## Quality/safety

- Recently acquired marker
- Recently salvaged history
- Optional extra confirmation for Unique/Gilded
- Warning when attempting to unlock an item used in a loadout
- Backup/export of QoL metadata only
- Recovery mode if stored item IDs no longer resolve after a game update

## Long-term possibilities

- Advanced filtering/search
- inventory statistics
- duplicate overview
- blacksmith tracking
- stash-style logical groups without changing the underlying inventory
